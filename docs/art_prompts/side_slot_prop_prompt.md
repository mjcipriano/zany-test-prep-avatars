# Side Slot Prop Prompt

Create a transparent PNG floating side-slot item for a teen-focused SAT prep mobile app. Item floats beside the avatar and does not need to be held. It should be clean, readable, stylish, and suitable for left or right side slots. Transparent background. Use consistent lighting and outline style. Avoid tiny details.

Additional constraints:
- Canvas: 512x512 PNG with alpha.
- Do not draw fingers, hands, arms, or grip alignment.
- Do not cover the avatar face when placed in any side slot.
- Support mirroring unless a separate left/right variant is created.
- Output should match `style_version: teen_modular_v1`.
