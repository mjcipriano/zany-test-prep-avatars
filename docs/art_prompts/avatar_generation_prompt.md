# Avatar Generation Prompt

Create a transparent PNG avatar for a teen-focused SAT prep mobile app. Style is modern, cool, clean, semi-flat cartoon with light cel shading. Character is waist-up to upper-thigh crop, centered, readable at small sizes, with simplified hoodie/jacket shapes and clear accessory zones. Avoid childish proportions, avoid full-body tiny figures, avoid excessive clothing folds, avoid complex hair that prevents hats. Transparent background. Consistent head position and torso scale. Designed for modular overlays including hats, glasses, chains, badges, jackets, auras, and side-slot companions.

Additional constraints:
- Canvas: 512x512 PNG with alpha.
- Framing: waist-up or upper-thigh, not full body.
- Keep face, head, neck, chest, and shoulders clean for overlays.
- No text or logos unless provided as a separate approved brand mark.
- Output should match `style_version: teen_modular_v1`.
